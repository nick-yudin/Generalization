EXPERIMENTS COVERED
===================

Total: 12 runs (4 experiments × 3 seeds)

1. Baseline-001
   - Seeds: 42, 43, 44
   - K=1, no position diversity, no template diversity, no anchors

2. I1_001_1 (Position Steering)
   - Seeds: 42, 43, 44
   - K=4, position diversity + curriculum, no template diversity, no anchors

3. I1_002_ALIBI (Negative Result)
   - Seeds: 42, 43, 44
   - K=4, position + template diversity, anchors, ALiBi positional encoding

4. I1_002a (Full Intervention)
   - Seeds: 42, 43, 44
   - K=4, position + template diversity, anchors, learned positional embeddings

USAGE QUICK REFERENCE
======================

View results:
  cat final_paper_results.json

Generate figures (Colab):
  1. Upload plot_paper_figures.ipynb to Colab
  2. Upload training_curves.json and final_paper_results.json
  3. Run all cells

Generate figures (local):
  jupyter notebook plot_paper_figures.ipynb

Reproduce experiment:
  python unified_paper_experiment_v2.py \
    --experiment i1_002a \
    --seed 42 \
    --output_dir my_runs/i1_002a_seed42

Aggregate results:
  python quick_aggregate.py --runs_dir my_runs
