================================================================================
MAIN RESULTS
================================================================================

Position Curriculum + Template Diversity SOLVES Position-Shift Problem:

  Baseline:  Eval-A 96.8%,  Eval-B 14.9%,  Eval-C0  1.2%  ← catastrophic cliff
  I1_002a:   Eval-A 96.0%,  Eval-B 73.7%,  Eval-C0 80.5%  ← robust!

  Improvements: Eval-B +58.8 pp,  Eval-C0 +79.3 pp

ALiBi Negative Result: Eval-A 21.4% (complete failure in char-level parsing)

QUICK START
================================================================================

1. VIEW RESULTS (30 sec):
   cat final_paper_results.json | python -m json.tool

2. GENERATE FIGURES (5 min):
   - Upload plot_paper_figures.ipynb to Google Colab
   - Upload training_curves.json + final_paper_results.json
   - Run all cells

3. REPRODUCE EXPERIMENTS (20 min/run):
   python unified_paper_experiment_v2.py \
       --experiment i1_002a --seed 42 --output_dir my_runs/i1_002a_seed42
